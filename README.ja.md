## 🚀 自己紹介

**シナ・カンザデー** — **Web、モバイル、デスクトップ、IoT** 分野で **10年以上** の実務経験を持つフルスタック開発者兼AIエンジニアです。ピクセルパーフェクトなインターフェースからスケーラブルなバックエンドアーキテクチャまで、品質と職人技に絶え間なく焦点を当てたエンドツーエンドのデジタル製品の提供を専門としています。
